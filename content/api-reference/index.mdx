API Reference は OpenAPI 仕様（`api-reference/openapi-public.json`）から自動生成されます。
仕様ファイルは製品側の CI から自動的に届き、全エンドポイントのページと**ブラウザ上で試せるプレイグラウンド**がここに展開されます。

**公開予定の内容**: CRM 例題（会社・担当者・商談・見積）のテーブルに対する CRUD エンドポイント一式と、リクエスト/レスポンスのコードサンプル(多言語)。
