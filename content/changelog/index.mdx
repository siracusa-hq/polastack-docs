## このページの運用について

- **API の変更**: API Reference の元になる OpenAPI 仕様はリポジトリ上で更新履歴が管理され、
  変更はすべて Pull Request として記録されます。ここには重要な変更（破壊的変更・メジャーバージョン）のみ
  ハイライトとして掲載します
- **SDK の変更**: リリースごとのハイライトを掲載します
- **ドキュメント自体の変更**: 大きな構成変更があった場合に記載します
