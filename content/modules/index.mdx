---
title: "Modules"
description: "Polastack を構成するモジュールの概要"
---

Polastack は以下のモジュールで構成されます。
各モジュールの詳細ガイドは順次公開します。

| モジュール | 概要 |
| --- | --- |
| Auth | 認証・認可（ユーザーログイン・M2M・SSO） |
| Database | スキーマ定義とデータ管理。テーブルを定義すると REST API が自動で使えるようになります |
| Gateway | API の入口。ルーティング・OpenAPI 仕様の動的生成 |
| Events | イベント配信・トリガー |
| Billing | 課金・サブスクリプション管理 |
| Hosting | アプリケーションのホスティング |
| Search | 横断検索 |
| Observability | ログ・監視 |
| Analytics | 利用状況の分析・集計 |
| Config as Code | 構成をコードとして管理し、レビュー・バージョン管理を可能に |

<Note>
**公開予定の内容**: 各モジュールに「何ができるか → 最小の動く例 → 主要ユースケース」の型で
個別ガイドを用意します（例題は CRM の世界で統一）。完成度の高いモジュールから順次公開します。
</Note>
