---

Polastack は以下のモジュールで構成されます。
各モジュールの詳細ガイドは順次公開します。

| モジュール | 何ができるか・どんな時に使うか |
| --- | --- |
| Auth | ユーザーのログイン・SSO・プログラム向けのクライアント認証を担います。「誰がアクセスできるか」の制御はここが起点です。詳しくは[認証・認可モデル概要](/content/getting-started/auth-model)へ |
| Database | テーブルとレコードの管理。テーブルを定義すると REST API が自動で使えるようになります。CRM 例題の companies・deals はここに作ります |
| Gateway | API の入口。ルーティングと、テーブル定義からの OpenAPI 仕様の自動導出を担います。API Reference の元になる層です |
| Events | データの変化をきっかけに処理をつなげるイベント配信。「商談が won になったら通知する」のような連携に使います |
| Billing | 課金・サブスクリプションの管理。作ったサービスを SaaS として提供するときの料金まわりを担います |
| Hosting | アプリケーションのホスティング。作ったフロントエンドの配信先です |
| Search | 横断検索。会社名・商談名をまたいで探すような検索体験に使います |
| Observability | ログ・監視。システムで何が起きたかを追跡します |
| Analytics | 利用状況の分析・集計。「ステージ別の商談金額の集計」のような可視化に使います |
| Config as Code | テーブル定義などの構成をコードとして管理し、レビュー・バージョン管理・環境間の再現を可能にします |

<Note>
**公開予定の内容**: 各モジュールに「何ができるか → 最小の動く例 → 主要ユースケース」の型で
個別ガイドを用意します（例題は CRM の世界で統一）。完成度の高いモジュールから順次公開します。
</Note>
